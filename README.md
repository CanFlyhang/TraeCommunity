# TRAE中文社区客户端

这是一个将TRAE中文社区网站转换为多平台客户端应用的项目，支持Windows、macOS和Android系统。

## 项目介绍

TRAE中文社区客户端是通过将网站转换为桌面和移动应用程序，让用户可以更方便地访问TRAE中文社区的内容，无需打开浏览器即可使用。

## 支持平台

- **Windows**：适用于64位Windows系统
- **macOS**：适用于64位macOS系统
- **Android**：适用于Android移动设备

## 安装说明

### Windows系统
1. 进入 `Win` 目录
2. 下载 `TRAE_CN_Community_0.0.1_x64-setup.exe` 安装包
3. 双击运行安装程序，按照提示完成安装
4. 安装完成后，在桌面或开始菜单中找到应用图标，点击启动

### macOS系统
1. 进入 `Mac` 目录
2. 下载 `TRAE_CN_Community_0.0.1_x64-setup.dmg` 安装包
3. 双击打开dmg文件，将应用拖入Applications文件夹
4. 从Applications文件夹启动应用

### Android系统
1. 下载Android安装包（.apk文件）
2. 在设备上启用「未知来源」安装权限
3. 找到下载的.apk文件并点击安装
4. 安装完成后，从应用抽屉中启动应用

## 功能特点

- **桌面级体验**：提供与网站相同的功能，但具有桌面应用的便捷性
- **离线访问**：部分内容可在离线状态下访问
- **系统通知**：接收社区的最新通知和消息
- **自动更新**：应用会自动检查并提示更新
- **多平台同步**：在不同设备上保持一致的使用体验

## 技术实现

该应用使用Web技术将TRAE中文社区网站封装为桌面和移动应用，确保用户获得与网站相同的功能和体验。

### 生成工具

本项目的安装包是通过GitHub上的开源项目 [PakePlus](https://github.com/Sjj1024/PakePlus) 生成的。PakePlus是一个将网页打包为桌面应用的工具，支持多平台输出，使我们能够快速将TRAE中文社区网站转换为可在Windows、macOS和Android系统上运行的应用程序。
